Nicomachos Food Graph　v0.3

料理の情報を、AIが間違えずに答えられる形に。

NFG は、料理・食材・アレルゲンの情報を「店主が確かめた正解データ」として持つための、食のオープンな規格です。株式会社NGraph が策定し、OMISEAI で実装しています。

AIは、料理を推測で答えてしまう。

AIは、材料やアレルゲンを、それらしく推測して答えます。

飲食店では、その一言が事故になります。

NFG は、店主が確かめた情報を正解データ（VAD）として持ち、AIはそれだけで答えます。

AIが下書きし、人が確かめる。

この仕組みを HITL（Human-in-the-loop）と呼びます。

  1. 01AIが下書きするメニューの写真や文章から、材料・調理法・アレルゲンを推定する
  2. 02店主が確かめる違うところを直し、正しいものを承認する
  3. 03正解データになる店主確認済み（owner_verified）・確かさ 0.95 以上
  4. 04AIが答える確かめた情報だけで答え、「店舗確認済み」と示す
分からないことは、店主への質問として戻す

情報には、出どころを付ける。

料理の情報ひとつひとつに、どこから来たか（vadSource）と、確かさ（confidenceScore 0.0〜1.0）を付けます。

ai_inferredAIの推測写真や文章からの推定。答えには使わず、店主への確認に回す

official_published公式に公開された情報店のサイト・公式メニュー
owner_verified店主確認済み（VAD）店主が確かめた正解データ。AIが答えに使う

この規格を、お店で動く形にしたのがOMISEAI。

料理ごとのカードに、確かめた情報だけを持ち、海外のお客さまの言葉で答えます。福井・金沢の実店舗で本番運用中です。

同じ料理・食材の辞書で、飲食店のホームページを英語・中国語・韓国語にしています（店ごとに訳がぶれない）。

N は、『ニコマコス倫理学』の N。

NFG の N は Nicomachos。二千四百年前にアリストテレスが『ニコマコス倫理学』で問うた、人間の幸福から取っています。

自律的に動く AI の時代に、人間の幸福という価値観をどう残すか。NGraph の N も同じ N で、会社全体で N×AI に取り組んでいます。NFG（食）は、その一つです。

なぜ、食からなのか。

人間社会で、食はなくなりません。AI も、食の知識を参照し続けます。その標準規格に N が入れば、AI の倫理や制御に貢献できる。この仮説を、実際に広く使われる規格にすることで確かめていきます。

技術者の方へ

schema.org を拡張する JSON-LD の語彙として使えます。

名前空間
https://nfg.ngraph.jp/schema/v0.3/
JSON-LD context
/schema/v0.3/context.jsonld
v0.2：/schema/v0.2/context.jsonld
例（架空の店）
{
  "@context": [
    "https://schema.org",
    "https://nfg.ngraph.jp/schema/v0.3/context.jsonld"
  ],
  "@type": ["Restaurant", "nfg:SeafoodRestaurant"],
  "name": "Sakanaya (fictional)",
  "hasMenu": {
    "@type": "Menu",
    "hasMenuItem": [{
      "@type": ["MenuItem", "nfg:Dish"],
      "name": "Boiled snow crab",
      "nfg:mainIngredients": ["snow crab"],
      "nfg:scientificName": "Chionoecetes opilio",
      "nfg:seasonStart": "11-06",
      "nfg:seasonEnd": "03-20",
      "nfg:vadCertified": true,
      "nfg:vadSource": "owner_verified",
      "nfg:confidenceScore": 0.95
    }]
  }
}
型
nfg:SeafoodRestaurantnfg:CocktailBarnfg:KappoRestaurantnfg:KaisekiRestaurant v0.3 で追加nfg:Dishnfg:Ingredient
プロパティ
  • nfg:vadCertified店主確認済みか（真偽）
  • nfg:vadSource確かめた出どころ（下の4つ）
  • nfg:confidenceScore確かさ 0.0〜1.0
  • nfg:culturalContext海外の方への文化的な背景
  • nfg:cookingMethods調理法（複数）
  • nfg:dishCategory料理の分類
  • nfg:mainIngredients主な材料（複数）
  • nfg:courseFlowコースの流れ（順番つき）v0.3 で追加
  • nfg:provenance産地・仕入れ
  • nfg:scientificName学名（魚・蟹など）
  • nfg:habitat生息域（例：水深200〜600m）v0.3 で追加
  • nfg:certificationTag産地や品質の認証の札（例：越前がにの黄色いタグ）v0.3 で追加
  • nfg:seasonStart旬の始まり（MM-DD）
  • nfg:seasonEnd旬の終わり（MM-DD）
